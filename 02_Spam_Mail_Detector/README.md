# Spam Mail Detector

## Objective

Build a Machine Learning model capable of classifying emails as Spam or Ham using Natural Language Processing.

---

## Dataset

SMS Spam Collection Dataset

Target:

- Spam
- Ham

---

## Libraries Used

- Pandas
- NumPy
- Scikit-Learn
- NLTK

---

## Workflow

- Load Dataset
- Text Cleaning
- Stopword Removal
- Tokenization
- TF-IDF Vectorization
- Train-Test Split
- Model Training
- Prediction

---

## Algorithms

- Multinomial Naive Bayes
- Logistic Regression

---

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

---

## Results

The model achieved high accuracy in detecting spam messages.
