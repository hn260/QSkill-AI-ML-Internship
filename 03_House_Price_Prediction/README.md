# House Price Prediction

## Objective

Predict house prices using regression algorithms based on housing features.

---

## Dataset

Boston Housing Dataset

Features include:

- Number of Rooms
- Crime Rate
- Tax Rate
- Distance to Employment Centres
- Age
- etc.

Target:

- House Price

---

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

---

## Workflow

- Load Dataset
- Data Cleaning
- Exploratory Data Analysis
- Feature Scaling
- Train-Test Split
- Linear Regression
- Prediction

---

## Algorithm

- Linear Regression

---

## Evaluation Metrics

- Mean Squared Error
- Root Mean Squared Error
- R² Score

---

## Results

The regression model accurately predicts house prices based on the available features.
